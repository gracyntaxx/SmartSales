### ✅ **Task for Member 1 – Data Cleaning**

**Title:** Clean the Amazon dataset and keep only smartphone‑related products.

**Goal:**  
Preprocess the dataset so that:
- Only **mobile phones / smartphones** are present.  
- All price, rating, and rating‑count columns are **clean numeric values**.  
- Duplicate rows and missing values are removed.  
- The final dataset is ready for EDA and ML.

**Dataset path they should use:**  
`data/amazon.csv` (inside your project folder).

***

#### Step‑by‑step instructions for Member 1

1. **Open the file and write the function**
   - Open `src/data_cleaning.py` in VS Code or Jupyter Notebook.  
   - Start with this:

     ```python
     import pandas as pd

     def load_and_clean_data(path):
         # 1. Load dataset
         df = pd.read_csv(path)

         print("Original number of rows:", len(df))
         return df


     if __name__ == "__main__":
         df = load_and_clean_data("data/amazon.csv")
         print(df.head())
     ```

   - Run this once to **check if the file opens correctly** and the columns appear.

2. **Remove duplicate rows**
   - Add this line inside the function (after loading):

     ```python
     df = df.drop_duplicates()
     print("Rows after removing duplicates:", len(df))
     ```

   - Explain in 1 line in your notes:  
     “We remove exact duplicate rows so that each product is counted only once.”

3. **Filter only smartphone / mobile‑phone products**
   - Add this block:

     ```python
     # List of keywords that usually appear in phone names
     phone_keywords = [
         "iphone", "samsung", "galaxy", "redmi", "xiaomi",
         "oneplus", "realme", "oppo", "vivo", "motorola",
         "pixel", "mobile", "smartphone"
     ]

     # Convert product_name to lowercase and check if any keyword is present
     mask = df["product_name"].str.lower().str.contains(
         "|".join(phone_keywords),
         na=False
     )
     df = df[mask]

     print("Rows after keeping only mobile phones:", len(df))
     ```

   - In your notes, write:
     - “We filter rows where the product name contains words like ‘iphone’, ‘samsung’, ‘mobile’, etc., so only phones remain.”
     - “If it’s a charger or cable with no such word, it will be removed.”

4. **Clean the price columns (`discounted_price`, `actual_price`)**
   - Add this:

     ```python
     # Remove ₹ sign and commas, then convert to float
     df["discounted_price"] = (
         df["discounted_price"]
         .replace("[₹,]", "", regex=True)
         .astype(float)
     )

     df["actual_price"] = (
         df["actual_price"]
         .replace("[₹,]", "", regex=True)
         .astype(float)
     )
     ```

   - In your notes:
     - “We remove ₹ and commas from price columns and convert them to numbers so the model can understand them.”

5. **Clean `discount_percentage`**
   - Add:

     ```python
     # Remove % sign and convert to float
     df["discount_percentage"] = (
         df["discount_percentage"]
         .replace("%", "", regex=True)
         .astype(float)
     )
     ```

6. **Clean `rating_count` (our sales proxy)**
   - Add:

     ```python
     # Convert to string, remove commas, then convert to numeric
     df["rating_count"] = (
         df["rating_count"]
         .astype(str)
         .str.replace(",", "")
     )
     df["rating_count"] = pd.to_numeric(df["rating_count"], errors="coerce")
     ```

   - In your notes:
     - “We treat more ratings as higher demand / more sales.”
     - “We remove commas so ‘24,269’ becomes 24269.”

7. **Clean `rating` column**
   - Add:

     ```python
     df["rating"] = pd.to_numeric(df["rating"], errors="coerce")
     ```

8. **Drop missing values**
   - Finally:

     ```python
     # Remove rows with missing values in any of these columns
     df = df.dropna()

     print("Final rows after dropping missing values:", len(df))
     print("First 5 rows of cleaned data:")
     print(df[["product_name", "discounted_price", "actual_price",
               "discount_percentage", "rating", "rating_count"]].head())
     print("\nData info:")
     print(df.info())
     ```

9. **Save the cleaned data to a new CSV**
   - Add at the end of the `if __name__ ...` block:

     ```python
     # Save cleaned smartphone‑only data
     cleaned_path = "data/cleaned_smartphones.csv"
     df.to_csv(cleaned_path, index=False)
     print("Cleaned data saved to:", cleaned_path)
     ```

   - Member 1 should:
     - Run `python src/data_cleaning.py` from the project root.
     - Check the printed numbers:
       - Original rows → after duplicates → after filtering phones → after dropping missing values.
     - Open the saved `cleaned_smartphones.csv` in Excel or Jupyter briefly to see that only phones look there.

10. **Small document / comment notes (for viva)**
    - Member 1 should write 3–4 lines in `report/report.docx` under a section called **“Data Cleaning”**:
      - Example:  
        “We removed duplicate rows and filtered only smartphone‑related products using keywords. We converted price, discount, rating, and rating‑count into numeric form. Finally, we removed any rows with missing values so the dataset is clean and ready for EDA and ML.”

3. **Graph 1 – Price vs Rating**
   - Cell:

